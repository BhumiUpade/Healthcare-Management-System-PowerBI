
# Healthcare Management System – Power BI Dashboard

## Project Overview
An interactive Healthcare Management System dashboard developed using Microsoft Power BI to analyse hospital Emergency Room (ER) patient data and present healthcare insights through visual reports.

## Dashboard Pages

The dashboard consists of **3 interactive pages**:

### 1. Consolidated View
- Displays an overall summary of hospital emergency room activities.
- Shows key performance indicators such as total patients, average wait time, patient satisfaction score and referred patients.
- Includes admission status, patient demographics, department referrals and waiting-time analysis.

### 2. Monthly View
- Provides a month-wise analysis of emergency room patient data.
- Includes Year and Month Name filters.
- Displays monthly patient statistics, waiting times, satisfaction scores and patient referral information.
- Helps explore trends in hospital activity over time.

### 3. Patient Details
- Provides a dedicated page for patient-level information.
- Allows users to explore detailed patient records and related information.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- Data Modelling
- Data Visualization
- DAX

## Key Features
- Interactive dashboard navigation.
- Date and month-based filtering.
- KPI cards and visual reports.
- Patient admission and demographic analysis.
- Healthcare operational data visualization.

## Data Preparation
- Created a Date Table.
- Established a one-to-many relationship between the Date Table and Patient Admission Date.
- Prepared healthcare data for reporting and visualization.
